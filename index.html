Le langage C#

C# se prononce « C sharp ». C’est un langage généraliste, typé et orienté objet, créé chez Microsoft pour écrire des applications qui tournent sur la plateforme .NET.

Ce que désigne C#

Deux noms reviennent tout le temps. Ils ne désignent pas la même chose.

C#, le langage

C# décrit comment écrire le programme : les types, les classes, les méthodes, les conditions. Sa syntaxe rappelle Java et C++, avec un point-virgule en fin d’instruction et des accolades pour les blocs.

Le symbole # est un clin d’œil au dièse musical. Un dièse monte la note d’un demi-ton. De la même façon, C++ « incrémente » C, et C# se place un cran au-dessus.

.NET, la plateforme

.NET fournit les bibliothèques (fichiers, réseau, collections, web) et le runtime qui exécute le programme. On écrit en C#. On s’appuie sur .NET.

Le même langage sert pour une API web, un outil en ligne de commande, une application de bureau ou un jeu Unity.

Quelques repères

Le langage a plus de vingt ans. Chaque version a ajouté une idée devenue courante.

  1. 2002

    C# 1.0

    Classes, propriétés, première version avec .NET Framework.

  2. 2005

    Génériques

    C# 2.0 : des listes typées, comme List<string>.

  3. 2007

    LINQ

    C# 3.0 : interroger des collections avec Where et des lambdas.

  4. 2012

    async / await

    C# 5.0 : écrire du code asynchrone qui se lit comme du code synchrone.

  5. 2020

    Records

    C# 9 : types concis pour les données, et instructions de premier niveau.

  6. 2025

    C# 14

    Version stable actuelle, livrée avec .NET 10. C# 15 est en préversion avec .NET 11.

Six idées à retenir

Ces notions reviennent dans presque tous les programmes C#.

Typage statique

Chaque valeur a un type connu à la compilation. var ne rend rien dynamique : le compilateur déduit le type.

Objets

Une classe regroupe des données et des comportements. L’encapsulation passe souvent par des propriétés.

LINQ

Filtrer, trier et projeter une collection sans écrire la boucle à la main. Le style est proche d’une requête.

async / await

Une opération longue (fichier, réseau) peut rendre la main. await reprend la suite quand le résultat arrive.

Mémoire gérée

Le ramasse-miettes libère les objets qui ne sont plus utilisés. On ne libère pas la mémoire à la main, comme en C.

Multiplateforme

.NET moderne s’exécute sur Windows, Linux et macOS. Le langage reste le même.
